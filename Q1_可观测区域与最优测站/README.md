# 问题 1 单目标（T1）的可观测区域与最优观测站

## 1 题意、已知与约束

**目标**：告警 T1：(θ, R, H) = (30°, 40 m, 45 m) → 水平位置
`T1' = (50 + 40cos30°, 50 + 40sin30°) = (84.6410, 70.0000)`，三维位置 `T1 = (84.6410, 70.0000, 45)`。

**测站可行性（三项约束，必须同时满足）**

| 约束 | 数学表达 |
|---|---|
| 车辆几何 | 圆心 `(x,y) ∈ [1.5, 98.5]²`，且到任一建筑原始轮廓的欧氏距离 `≥ 1.5 m`（圆盘不与建筑相交） |
| 视线遮挡 | 线段 `(x,y,2)–(84.641,70,45)` 与任一闭长方体 `[x1,x2]×[y1,y2]×[0,h]` 交集为空（相切/接触即算遮挡） |
| 云台仰角 | `el = atan2(43, r) ∈ [−10°, 80°]`，其中 `r` 为相机到目标的水平距离 |

**指标**：`Q = 1/r`（单位 m⁻¹），越大越好。

**优化准则（明确写出）**

```
max  Q(s) = 1/r(s)
s.t. s ∈ F = { 几何可停留 } ∩ { 视线通视 } ∩ { el(s) ∈ [-10°, 80°] }
```
即：在所有同时满足三项约束的测站中，取到目标水平距离最小者。因 `Q` 关于 `r` 严格单调递减，
该准则等价于 `min r`，且最优值与"目标-测站"的水平距离一一对应，不受方位角偏好影响，因此是一个
**与几何构型无关、可复现的标量准则**。

## 2 求解方法与比较

| 项目 | 方法 A：均匀网格扫描 | 方法 B：解析下界 + 弧枚举（采用） |
|---|---|---|
| 代码 | `code/method_A_grid.py` | `code/method_B_analytic.py` |
| 结果文件 | `output/method_A_grid.json` | `output/method_B_analytic.json` |
| 图形 | `figures/Q1_obs_region_T1.png`、`figures/Q1_zoom.png` | `figures/Q1_optimal_arc.png` |
| 精度 | 受网格限制：0.2 m 网格给出 `r = 7.5828 m`（相对误差 +0.01%） | 精确：`r* = 7.5821 m`，给出最优性证明 |
| 最优值 | `Q = 0.131878 m⁻¹` | `Q* = 0.131890 m⁻¹` |
| 耗时 | 0.22 s（25.1 万点） | 1.3 s（含 3.6 万点弧枚举与复核） |
| 优点 | 直观、同时给出整个区域图像与面积统计 | 有最优性证明、能识别"平局是结构性的"、精度不受分辨率限制 |
| 缺点 | 无法证明最优；接近约束边界时易漏判 | 需先做解析推导；对多约束耦合的一般情形不易推广 |
| 结论 | 作**可视化与交叉验证**（二者 r 相差 0.0007 m） | **作为最终答案** |

## 3 结果

### 3.1 可观测区域

- 可停留面积 **8302.6 m²**，其中可观测面积 **5607.8 m²**（占 67.5%）。
- 遮挡是主要限制：仅因视线遮挡被排除的面积 **2537.4 m²**（63435 个网格点），集中在 **B2（28 m）西侧与西南侧的阴影带**、
  B5 以南、B4 以北等方向；B2 距 T1 仅 5.6 m，其阴影呈长条状覆盖区域中部。
- 仰角约束只在**目标附近**起作用：排除 `r < 7.582 m` 的圆盘（面积约 180 m²）。

### 3.2 最优测站（最终答案）

| 项 | 值 |
|---|---|
| 最优水平距离 `r*` | **7.5821 m**（= (45−2)/tan80°，由仰角上界决定） |
| 视线仰角 | **80.00°**（云台上限，约束起作用） |
| 观测质量 `Q* = 1/r*` | **0.131890 m⁻¹** |
| 选定测站坐标 | **(88.8247, 76.3233)**（目标方位 56.51°，即 T1 的东北方向） |
| 该点净空（到建筑/边界） | 9.674 m |
| 到调度中心 O 的行驶时间 | 2.788 s（V4 出发） |

**最优性证明**：仰角约束给出 `r ≥ (H−2)/tan80° = 7.58206 m`；`Q = 1/r` 单调递减，故
`Q ≤ 0.131890 m⁻¹`；在圆 `r = 7.58206` 上确实存在可行点（已用解析判据与 1 mm 采样独立复核），
故该上界可达，即为全局最优。

### 3.3 平局结构与裁决规则

最优集**不是单点，而是一段圆弧**：`r = r_lb` 圆上可行弧长 **283.85°**（占圆周 78.85%），
被 B2 挡住的扇区为 160.8°→236.9°（正西方向）。圆上任意点 `Q` 完全相同，
因此必须给出裁决规则（题目明确要求）：

> **R1（主）** 在最优集内最大化"到建筑与边界的最小净空"——净空越大，车辆定位误差、云台指向误差
> 都不会把测站推到不可观测区或阴影边界上，工程上最稳；
> **R2（次）** 净空并列时取离调度中心 O 最近者，缩短部署时间；
> **R3（末）** 仍并列时取目标→测站方位角最小者，保证结果唯一、可复现。

按 R1–R3 得到 (88.82, 76.32)；若只按"离 O 最近"裁决，会选到 (80.50, 63.65)——该点净空为 0 m，
紧贴 B2 的 1.5 m 禁入边界，任何微小定位误差都可能使车辆侵入建筑，故被 R1 排除。

### 3.4 敏感性：把仰角上界收紧的"鲁棒变体"

`Q = 1/r` 的最优点必然落在约束边界（仰角 80°）上，数学最优但工程上处于极限状态。
若要求仰角留有余量：

| 仰角上限 | `r_lb` | `Q` | 相对 `Q*` 损失 |
|---|---|---|---|
| 80°（题目给定） | 7.582 m | 0.13189 | 0 |
| 78° | 9.140 m | 0.10941 | 17.0% |
| 75° | 11.522 m | 0.08679 | 34.2% |
| 70° | 15.651 m | 0.06390 | 51.6% |

**部署建议**：若只追求单站观测质量，取 80° 边界点；若需考虑定位/指向误差，建议在 78° 上限内布站
（`r ≈ 9.1 m`），代价是 Q 下降 17%，但把"仰角越界即无法观测"的风险降为 0。

## 4 验证

- `common/output_model_validation.json`：几何可停留（2 万点 0 不一致）、视线遮挡（1800 个样本 0 不一致，
  与 1 mm 步长采样完全一致）、最短路（0 穿墙采样点，与 0.25 m 栅格误差 ≤ 2.8%）。
- 方法 A 与方法 B 独立得到的最优 `r` 相差 0.0007 m（网格分辨率量级），互相印证。
- 最优测站三项约束逐条复核：`可停留=true`、`视线遮挡=false`（解析+采样双判据）、`仰角 80.00° ∈ [−10,80]`。
