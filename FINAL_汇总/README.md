两处曾经出现、已定位并修复的口径错误（记录在此以免复现）：

## 3. 逐题最终答案

### 问题 1：可观测区域与 T1 最优测站

**约束统计**（0.2 m 网格，25.1 万点）：

| 项 | 数值 |
|---|---|
| 区域内网格点 | 251 001 |
| 几何可停留（边界 + 净空） | 207 565（可停留面积 **8302.6 m²**） |
| 仰角可行（≤80°） | 203 630 |
| 三项全满足（可观测） | 140 195（可观测面积 **5607.8 m²**） |
| **仅因视线遮挡被排除** | **63 435 点** |

即遮挡是本问的主导约束：它把可停留区域切掉了约 32% 的候选点。

**最终答案**

| 项 | 数值 |
|---|---|
| 最优测站 | **(88.8247, 76.3233)** |
| 水平距离 r | **7.5821 m** |
| 视线仰角 | **80.0°**（恰在上限） |
| 优化指标 Q = 1/r | **0.131890 /m** |
| 到建筑/边界净空 | **9.674 m** |
| 到调度中心 O 距离 / 行驶时间 | 46.907 m / 2.788 s |
| 最优集 | 最优圆上可行弧 **1 段**（236.9°→160.75°，弧长 283.85°，占全圆 **78.85%**） |

**最优性证明（解析，非数值）**：仰角约束 ⇒ r ≥ (H−2)/tan80° = (45−2)/5.6713 = 7.58206 m；
Q = 1/r 关于 r 严格单调减 ⇒ Q ≤ 1/r_lb = 0.131890；最优圆上存在满足遮挡与边界的点 ⇒ 该上界可达 ⇒ **全局最优**。
数值解 (7.5821) 与下界 (7.58206) 之差仅 0.04 mm，为离散化残差，可视为精确取到。

**平局裁决**（最优弧上 283.85° 全部同分，必须给出唯一工程解）：
① 净空最大（抗定位误差、远离遮挡阴影边界）→ ② 离 O 最近（部署/转场短）→ ③ 目标方位角最小（可复现）。

**敏感性**（仰角上限留余量时的 Q 损失，供工程妥协）：

| 仰角上限 | r_lb (m) | Q (/m) | 可行弧占比 | Q 相对损失 |
|---|---|---|---|---|
| 80°（题设） | 7.5821 | 0.131890 | 78.85% | — |
| 78° | 9.1399 | 0.109410 | 78.08% | −17.0% |
| 75° | 11.5218 | 0.086792 | 77.37% | −34.2% |
| 70° | 15.6507 | 0.063895 | 64.58% | −51.6% |

### 问题 2(1)：两站交会定位精度与 T2 最优测站对

**误差模型**：δαᵢ ~ N(0, (1°)²) 独立，线性化 nᵢᵀδp = rᵢ δαᵢ ⇒
Cov(δp) = σ²A⁻¹diag(r₁², r₂²)A⁻ᵀ，det A = ±sin γ ⇒
**σ_p = σ·√(r₁²+r₂²)/|sin γ|**（位置误差 RMS，旋转不变）。

**最终答案**

| 项 | 数值 |
|---|---|
| 车辆对 | **V3 – V5** |
| 测站 1 / 测站 2 | **(5.3448, 73.7448)** / **(12.2737, 78.1841)** |
| r₁ = r₂ | **5.8188 m**（= 仰角 80° 下的下界） |
| 基线 B / 交会角 γ | 8.229 m / **90.0°** |
| 行驶时间 t₁ / t₂ | 5.001 s / 13.510 s |
| **σ_p** | **0.14362 m** |
| 误差椭圆 1σ（各向同性） | 0.10156 m 圆 |
| 95% 误差圆半径 | 0.2486 m |

**为什么这已是最优**：闭式结论 σ_p ≥ σ·√2·r_lb（r₁ = r₂ = r_lb 且 γ = 90° 同时取到），
理论下界 0.14362 m 与数值解**完全相同**；该组合下协方差各向同性，误差椭圆退化为圆。

**平局裁决**：0.5 m 栅格下有 **6 组**车辆对同达 σ* = 0.14364（因为最优圆上有很长弧段），
按 `max(t₁,t₂)` 最小取 **V3–V5（13.564 s，次优 20.215 s，裕度 6.7 s 绝对无争议）**，
再对该车辆对做 0.02 m 连续精修并投影到严格 γ = 90°。

**独立验证**：20 万次蒙特卡洛，经验 RMS = 0.14364 m vs 一阶模型 0.14362 m，**相对偏差 0.01%**。

**退化分析（对 Q2-2 的关键输入）**：σ_p ∝ 1/sin γ 在 γ→0°/180° 处爆炸（γ=1° 时 σ_p = 28.29 m），
故 Q2-2 引入 **γ ≥ 15°** 可用性假设（此时 1/sin γ = 3.86，σ_p 尚在米级）。

### 问题 2(2)：并发告警下的车辆复用与路径规划

**目标**：min t_last = max{三个告警的观测开始时刻}，允许一车连续服务两个告警。

**最终答案：t_last = 10.655 s**

| 告警 | 观测开始 | 车辆 | 测站 | r (m) | 仰角 | σ_p (m) | γ (°) |
|---|---|---|---|---|---|---|---|
| T1 | **2.678 s** | V3 + V5 | (13.5, 91.0) / (49.5, 93.5) | 74.18 / 42.28 | 30.1 / 45.5 | 5.004 | 17.33 |
| T2 | **10.255 s** | V2 + V4 | (72.5, 1.5) / (87.5, 71.5) | 93.91 / 76.48 | 19.4 / 23.3 | 2.828 | 48.37 |
| T3 | **10.655 s** | V3 + V1 | (13.5, 91.0) / (14.5, 14.5) | 90.47 / 45.35 | 30.4 / 49.5 | 2.090 | 57.67 |

**复用结构**：V3 先服务 T1、再服务 T3，**且两次用的是同一个测站 (13.5, 91.0)** ——
这是本问最关键的结构性发现：该点对 T1、T3 同时可观测，复用车辆无需转场，
省掉的不是行驶时间而是"5 s 观测 + 云台复位"之外的全部路程；伙伴车 V5、V1 各自独立。
T2 因方位相反（11.03, 72.5），由 V2、V4 独立承担。

**下界自校验**：t_last = T1 开始(2.678) + 观测 5 s + V3 转场 1.003 s + 云台复位 1.973 s
= 10.654 s ≈ 10.655 s，说明时间轴仿真无空等、无逻辑泄漏。

**与基线对比**（基线 = 最近分配启发式，不含复用）：

| 方案 | t_last (s) | 相对改进 | σ_p 均值 (m) |
|---|---|---|---|
| 基线（最近分配） | 19.691 | — | 2.933 |
| **本文（结构枚举 + 复用）** | **10.655** | **−9.036 s（−45.9%）** | 3.307 |
| 质量增强（γ≥60°, r≤45 m） | 16.843 | −14.0%（相对最优） | **0.788** |
| 退化对照（γ≥0.5°） | 10.655 | 0.000 | 3.307 |

两点必须说清：
- 质量增强版把 σ_p 均值压到 0.788 m（−76%），代价是 t_last 增至 16.843 s（+6.19 s）。这提供了**时间—精度 Pareto 前沿上的两个端点**，而非"更差的方案"。
- 退化对照与主方案同解 ⇒ **γ ≥ 15° 的假设在本算例中不起约束**，结论对 γ 下限的取值不敏感（这是好事：说明"为了满足交会角而牺牲时间"并未发生）。

### 问题 3：定位与指向误差对水平方位精度的影响

**参数**：r = 40 m，σ(s) = a + b·s = 0.3 + 0.02 s，云台零偏 0.8°、控制 0.6°，容差 ±5°，置信度 95%。

**模型**：δψ_geo ≈ (sin α·δx − cos α·δy)/r ⇒ σ_geo = σ(s)/r（**与方位角无关**）；
σ_Δψ(s) = √(σ_geo,deg(s)² + 0.8² + 0.6²)；
判据 P(|Δψ| ≤ 5°) ≥ 0.95 ⟺ 5/σ_Δψ ≥ z₀.₉₇₅ = 1.95996 ⟺ **σ_Δψ ≤ 2.55107°**。

**结果一：允许的最大行驶距离**

| 项 | 精确 (tan) | 小角近似 |
|---|---|---|
| 允许定位误差 σ_pos | **1.63936 m** | 1.63845 m |
| **s_max** | **66.968 m** | 66.922 m |
| 相对差 | — | −0.0685% |

s_max 距区域最大可行尺度（≈100 m）仍有充分余量，但**不足以覆盖全区域**——这是本题的实质结论。

**结果二：行驶 80 m 时的参数约束**

必须 **a + 80b ≤ 1.6394 m**。

| 情形 | 结论 |
|---|---|
| 标称 a = 0.3, b = 0.02（a + 80b = 1.90 m） | **不满足**（超限 0.26 m，P 仅 0.9156） |
| 固定 a = 0.3 | b ≤ **0.016742** |
| 固定 b = 0.02 | a ≤ **0.0394** |
| a = 0 | b ≤ 0.020492 |
| 可行域 | 三角形：a ∈ [0, 1.6394]，b ≤ (1.6394 − a)/80；a 越小允许的 b 越大 |

**关键中间量**：s = 0 时 σ_Δψ = 1.0884°（P = 0.999996），已是"地板"；到 80 m 时 2.8975°（P = 0.91558），缺口 0.3465°。
误差源等贡献点 s ≈ 19.91 m：不到 20 m 时云台自身误差（0.8°/0.6°）主导，超过后定位误差主导 ⇒ **优先改进云台零偏，比降低测距噪声更划算**。

**验证**：200 万次蒙特卡洛，σ_Δψ 最大绝对偏差 **0.0069°**；s_max 处 MC 通过率 **0.94971**（解析 0.95）；
KS 检验 p = 0.9168 / 0.6651（不拒绝正态）；二阶项相对偏差 ≤ 0.2445%，证明一阶线性化在本题量级下成立。

### 问题 4：扰动下的重调度

**扰动**：t = 5 s 发生，新告警（θ∈[0,360), R∈[30,50], H=50）／车辆失效（5 车等概率）／通信中断（t_rec ∈ (5,30]），重调度在 t_eff = max(5, t_rec) 生效。

**情景集**：93 个（单一-新告警 36、单一-失效 5、单一-通信 4、组合 48），
新告警按 θ 每 30° × R ∈ {30,40,50} 全网格覆盖（观测区域随方位变化剧烈），失效覆盖全部 5 车。
**评价准则按题意**：先比 η（成功获得 ≥2 站交会的告警比例），再比 t_last。

**总结果（93 情景）**

| 策略 | 平均 η | η@20s | 平均 t_last (s) |
|---|---|---|---|
| S0 沿用原计划 | 0.8566 | 0.6470 | 23.987 |
| **S1 在线重调度** | **1.0000** | **0.7151** | **22.374** |
| 差 | **+0.1434** | +0.0681 | **−1.613** |

**S1 更优 88 / 持平 5 / 更差 0**，η 提升 52 例，最大单项改进 **8.773 s**。

**分类结果（差异来源清晰）**

| 类别 | 情景数 | S0 → S1（η） | S0 → S1（t_last） | 更优/持平/更差 |
|---|---|---|---|---|
| 单一-新告警 | 36 | 1.000 → 1.000 | 25.033 → **19.801**（−5.23） | **36 / 0 / 0** |
| 单一-失效 | 5 | 0.733 → **1.000** | 10.847 → 11.842（+0.99） | **4 / 1 / 0** |
| 单一-通信 | 4 | 1.000 → 1.000 | 27.236 → 27.236 | 0 / 4 / 0 |
| 组合 | 48 | 0.750 → **1.000** | 24.300 → 24.995（+0.70） | **48 / 0 / 0** |

读法：**新告警类靠时间获益**（重新分配更近的车，省 5.2 s），**失效/组合类靠完备性获益**（η 从 0.73/0.75 补到 1.0，代价是 t_last 增加约 1 s——这是必要的，因为原计划已成不可行）。**通信类无差异**：通信恢复后原计划的剩余任务仍可执行，重调度无操作空间，说明 S1 不会为"扰动"而扰动。

**典型情景 B（θ=180, R=30, V2 失效）**：S0 中 T2 只剩 V4 一车 → η = 0.75；S1 把 V1 调给 T2（20.59 s）与 T4（20.83 s）配对，恢复双站交会，η = 1.0，t_last 20.009 → 20.835 s（+0.83 s 换 25 个百分点完备性，强占优）。

**典型情景 A（θ=300, R=50）**：T4 观测开始 25.314 → **18.748 s（−6.57 s）**，η 保持 1.0。

**共同的方法学原则**：每个子问题都保留 ≥2 条独立实现路径（解析 vs 数值、枚举 vs 元启发式、解析 vs 蒙特卡洛、枚举 vs 启发式），
并且**至少有一条不依赖优化搜索**（闭式下界 / 蒙特卡洛 / 手工推算），用于判定另一条是否真的收敛到最优。
所有子问题都做了"结果是否等于理论下界"的自校验。

## 6. 跨题一致性自检

汇总时最值得警惕的是"各题独立最优、拼接后自相矛盾"。已核对的闭环：

1. **仰角下界链条**：Q1 得 r_lb = (H−2)/tan80° = 7.58206（H=45）→ Q2(1) 同一公式用于 H=35 得 **5.8188 m**，与 Q2(1) 数值解精确吻合（说明两题共用同一临界判据，非巧合）。
2. **γ 下限链条**：Q2(1) 退化分析给出"γ<15° 时 σ_p 超米级"→ Q2(2) 采用 γ ≥ 15°，且退化对照（γ ≥ 0.5°）与主方案同解 ⇒ 假设不自相矛盾。
3. **基线一致性**：Q2(2) 的 t_last = 10.655 s 被 Q4 原样读入作为基线，Q4 输出中 `基线.t_last = 10.655` 完全一致。
4. **时间轴闭合**：Q2(2) 的 t_last 手算分解 2.678 + 5 + 1.003 + 1.973 = 10.654 ≈ 10.655 s，误差 1 ms 来自 1e-3 级的取整。
5. **模型单一口径**：五个子问题全部 `import common.model`，遮挡判定（闭长方体、含边界相切）、可停留（原始轮廓 ≥1.5 m）、云台速度（两轴取较长）无一处重复实现。

## 7. 结论与局限

**结论**：在题设约束下，(a) 单站最优由仰角上限决定、可解析给出且全局可达；(b) 两站交会的最小 σ_p 由 r 下界与 γ=90° 同时决定，闭式 0.14362 m 达到理论下界；(c) 三告警并发的最优解本质是"找一辆车在同一测站连续服务两个同向告警"，把 t_last 压到 10.655 s（较启发式快 45.9%）；(d) 指向精度的瓶颈在 80 m 处从定位误差主导，标称参数不满足要求；(e) 扰动下必须重调度，且重调度的价值主要不是省时间而是**恢复双站交会的完备性**。

**局限（已在各 README 中量化）**：
- 测站只在候选池（方位分箱 + 0.5 m 栅格）中选，未做全连续空间优化；Q2(2) 的 10.655 s 是"该离散化下的最优"，与连续最优的差距未给出严格界（下界自校验给出了 ≤ 1 ms 的时间轴一致性，但不是空间最优性证明）。
- Q4 的情景集是**分层设计**而非全枚举（全枚举为 36×5×4 量级以上），统计结论（88/5/0）在抽样意义下成立。
- 未建模风扰、通信时延抖动对观测本身的污染，仅把通信中断处理为"迟到的重调度触发"。
