# AI 使用说明（2026 数维杯 · B 题）

依据《数维杯全国大学生数学建模挑战赛人工智能工具使用规定（2026 年修订）》，本目录存放本队的 AI 使用申报材料。

## 一句话结论

本队使用了 **WorkBuddy（底层模型 DeepSeek-V4.1-Flash）**，使用日期 2026-11-20、2026-11-23；
申报材料已分三处落地：**论文附录 C**、**本目录的独立报告**、**全部脚本的文件头注释**。

## 文件清单

| 文件 | 作用 | 是否提交 |
|---|---|---|
| `AI工具使用情况报告.docx` | 完整报告（10 节，含签署页），可直接作为附件 | **是** |
| `AI工具使用情况报告.md` | 同一内容的纯文本源，便于改字与版本比对 | 随源归档 |
| `appendix_cn.tex` / `appendix_en.tex` | 论文附录 C 的源码（已由脚本插入两篇 main.tex） | 随源归档 |

| `code/insert_appendix.py` | 把附录与参考文献 [13] 写入两篇论文（幂等，可整块替换） | 随源归档 |
| `code/add_ai_headers.py` | 给 17 个脚本插入文件头注释块（幂等） | 随源归档 |

## 规定条款与本项目的对应

| 规定条款 | 要求 | 本项目的做法 | 落点 |
|---|---|---|---|
| 第 1 条 | AI 不得替代核心工作 | 模型假设取舍、算法选择、结果解读、结论判断由队员完成；AI 用于检索、实现、绘图、润色 | 报告第三节 |
| 第 2 条 | 须理解核验、自行改写，禁照搬 | 对 12 处错误逐项更正（E1–E12），文字重写；报告附承诺条款 | 报告第三、五节 |
| 第 3 条 | 论文正文结尾或文献后明确声明 | 两篇论文均加“附录 C”声明段 | `main.pdf` 末 |
| 第 4 条 | 生成内容逐项核对，虚构/错误/无源一律删除或更正 | E1–E12 更正清单：错的距离、误判的可行域、错误 DOI、无源条目全部改正或删除 | 报告第五节 |
| 第 5 条 | 正文标注 + 参考文献列出工具 | 图题与结果处标“（AI 辅助 Rk，队员复算）”；参考文献 [13] | 两篇论文 + 报告第六、七节 |
| 第 6 条 | 附《AI 工具使用情况报告》，按工具逐项填写 8 个字段 | 完整版 10 节；论文内的压缩版保留 8 字段表 | 本目录 + 附录 C |
| 第 7 条 | 代码注释标明工具、版本、开发机构、版本发布日期 | 17 个脚本文件头统一注释块 | 各 `code/*.py` |
| 第 8 条 | 数据分析/可视化/优化结果处注明 AI 贡献 | 图题末标注，配合 R 编号回溯 | 两篇论文 |

## 提交前必须由队员完成（报告第十节）

- [ ] 按本队行文习惯重写正文，去掉 AI 原始句式
- [ ] 填队号、学校、队员；填 `版本发布日期`（代码注释与报告各有 1 处 `______`）
- [ ] 在论文正文落位第六节给出的标注文字
- [ ] 三人签署

> **有两处空白是故意留的**：AI 工具的版本发布日期官方未公开给出准确日期，本队不应猜填；
> 队号与姓名只能由本人填写。除此之外，报告中的工具、日期、环节、错误更正清单均为实际记录，无需改动。

## 重新生成

```bash
python AI使用说明/code/make_docx.py        # md -> docx
python AI使用说明/code/add_ai_headers.py   # 补/修脚本注释块（幂等）
python AI使用说明/code/insert_appendix.py  # 写入两篇论文（幂等）
bash  PAPER_论文/code/build.sh             # 重编译两篇论文
```

改文字只改 `AI工具使用情况报告.md` 与 `appendix_cn.tex` / `appendix_en.tex`，然后按上面四条跑一遍即可，
不要直接编辑 `.docx`，否则下次生成会被覆盖。

## 一点提醒

规定第 1、2 条把“核心工作”划给队员。这份报告是按**实际发生的使用方式**填写的（AI 参与了模型与代码的
初稿、论文初稿与排版），因此它对“核心工作由队员独立完成”的表述，将以**报告第十节的三人签署**为凭。
签署前请确实逐项看懂并能独立复算，否则这份申报本身就成了不实陈述——第 4 条与第 9 条对此有明确后果。
