# 问题 3 定位与指向误差对水平方位精度的影响

## 1 题设与建模

| 量 | 设定 |
|---|---|
| 车辆定位误差 | `(δx, δy) = P̂ − P`，`δx, δy ~ N(0, σ(s)²)` 独立，`σ(s) = a + b·s`，标称 `a = 0.3 m, b = 0.02` |
| 云台零偏 | `ε_b ~ N(0, 0.8°²)` |
| 云台控制误差 | `ε_c ~ N(0, 0.6°²)` |
| 三者关系 | 相互独立；目标位置完全已知；车辆到目标水平距离固定 `r = 40 m` |

**定义**：`Δψ = 指令方位角 − 真实方位角`，卷绕到 `[−180°, 180°)`。

## 2 误差传播模型

`α = atan2(y_T − y_P, x_T − x_P)`，对车辆位置求偏导：

```
∂α/∂x_P =  (y_T−y_P)/r² = sin α / r
∂α/∂y_P = −(x_T−x_P)/r² = −cos α / r
```

一阶传播（delta 法）：

```
δψ_geo ≈ (sin α · δx − cos α · δy) / r
⇒ Var(δψ_geo) = σ(s)² (sin²α + cos²α) / r² = σ(s)² / r²
⇒ σ_geo(s) = σ(s)/r = (0.3 + 0.02 s)/40      [rad]
```

**关键结论**：`σ_geo` 与方位角 `α` 无关（各向同性），因此误差传播对"车辆从哪个方向看目标"不敏感，
只与行驶距离成正比。

综合三项独立误差：

```
σ_Δψ(s) = sqrt( σ_geo(s)² + 0.8² + 0.6² )   [deg]
        = sqrt( (arctan((0.3+0.02s)/40)·180/π)² + 1.0 )
```

## 3 结果一：满足 `P(|Δψ| ≤ 5°) ≥ 0.95` 的最大行驶距离

正态近似下 `P(|Δψ| ≤ 5°) = 2Φ(5/σ_Δψ) − 1 ≥ 0.95` ⟺

```
5/σ_Δψ ≥ z₀.₉₇₅ = 1.95996  ⟺  σ_Δψ ≤ 2.5511°
⟹ σ_geo ≤ sqrt(2.5511² − 1.0²) = 2.3469°
⟹ σ(s) ≤ 40·tan(2.3469°) = 1.6394 m
⟹ 0.3 + 0.02 s ≤ 1.6394  ⟹  s ≤ 66.97 m
```

| 项 | 值 |
|---|---|
| **最大允许行驶距离 `s_max`** | **66.97 m**（小角近似 66.92 m，差 0.07%） |
| `s = 0` 时 | `σ_Δψ = 1.088°`，`P = 0.999996` |
| `s = 66.97 m` 时 | `σ_Δψ = 2.551°`，`P = 0.9500`（恰在门限上） |
| `s = 80 m` 时 | `σ_Δψ = 2.898°`，`P = 0.9156 < 0.95`，**不满足**（超出 0.346°） |

## 4 结果二：行驶 80 m 时对 `a, b` 的约束

要求 `s = 80` 时仍满足同一精度，即 `a + 80b ≤ 1.6394 m`：

```
a + 80 b ≤ 1.6394 m,   a ≥ 0, b ≥ 0
```

可行域是三角形。等价写法与几个常用截面：

| 条件 | 结果 |
|---|---|
| 给定 `a = 0.3` | `b ≤ (1.6394 − 0.3)/80 = 0.01674 m/m` |
| 给定 `b = 0.02` | `a ≤ 1.6394 − 1.6 = 0.0394 m` |
| `a = 0` | `b ≤ 0.02049 m/m` |
| **标称值 `a=0.3, b=0.02`** | `a + 80b = 1.90 m > 1.6394 m` → **不满足** |

结论：标称参数下 80 m 行驶会破坏 5° 精度要求，必须把 `b` 从 0.02 降到 0.0167 以下
（定位误差增长率降低 16%），或把起始误差 `a` 压到 0.04 m 以下。

## 5 三个误差源的相对贡献

按方差分解（`σ_Δψ² = σ_geo² + 0.8² + 0.6²`）：

| `s` / m | 车辆定位 | 云台零偏 | 云台控制 | `σ_Δψ` / ° |
|---|---|---|---|---|
| 0 | 15.6% | **54.0%** | 30.4% | 1.088 |
| 20 | 50.1% | 31.9% | 18.0% | 1.416 |
| 40 | 71.3% | 18.4% | 10.3% | 1.866 |
| 60 | 82.2% | 11.4% | 6.4% | 2.369 |
| 66.97 | 84.6% | 9.8% | 5.5% | 2.551 |
| 80 | 88.1% | 7.6% | 4.3% | 2.898 |

**等贡献点**：`s ≈ 19.9 m`（定位项方差 = 云台两项方差之和）。

**解读**：近场（`s < 20 m`）方位偏差由**云台零偏**主导（0.8°，占一半以上），此时再怎么提高
定位精度都收效甚微；远场（`s > 20 m`）则由**累积定位误差**主导，且随 `s` 线性增长、按平方进入方差，
增长极快。云台控制误差（0.6°）始终是三者中最小的。

## 6 近似与数值方法的适用性论证

1. **一阶（delta 法）线性化**：二阶项量级约 `(σ/r)²/2`。在 `s = 80 m` 时 `σ/r = 1.9/40 = 0.0475`，
   二阶相对影响 ≈ 0.1%；用 40 万次抽样直接比较"精确 `atan2` 角度误差"与"一阶 `δy/r`"：

   | `s` / m | 精确 `σ_geo` | 一阶 `σ_geo` | 相对偏差 |
   |---|---|---|---|
   | 20 | 1.0050° | 1.0026° | +0.24% |
   | 66.92 | 2.3484° | 2.3455° | +0.12% |
   | 80 | 2.7249° | 2.7195° | +0.20% |

   相对偏差均 < 0.25%，且线性化略微**低估**，属保守方向可接受范围（对 `s_max` 的影响 <0.1 m）。

2. **正态近似**：`Δψ` 是"非线性函数 + 两个高斯"之和。KS 检验（30 万样本）：
   `s = 66.97`：KS = 0.00101，p = 0.917；`s = 80`：KS = 0.00133，p = 0.665 → **均不能拒绝正态**；
   偏度 |skew| < 0.004，峰度 |kurt| < 0.008。

3. **卷绕处理**：所有情景下 `|Δψ| > 179°` 的样本占比为 0（`σ_Δψ ≤ 3.4°`），
   卷绕不改变任何统计量，仅在形式上保证 `Δψ` 落在 `[−180°, 180°)`。

4. **蒙特卡洛一致性**：200 万样本，`P(|Δψ| ≤ 5°)` 的解析值与经验值最大差 3×10⁻⁴
   （相对误差 < 0.04%），`σ_Δψ` 相对差 < 0.25%（来自上述二阶效应）。

## 7 实际部署建议

1. **行驶距离红线 67 m**：单程累计行驶超过 67 m 后，5°/95% 的指向精度无法保证；
   若任务要求更远，应在途中设置"重新定位点"（用已知地标/标定板重置累计误差），
   相当于把 `s` 截断，而非让 `σ(s)` 一路增长。
2. **近场优先治云台**：`s < 20 m` 时零偏 0.8° 占方差 54%，应先做云台零偏标定
   （把 0.8° 降到 0.3° 可使 `σ_Δψ(0)` 从 1.09° 降到 0.67°，提升 39%），而不是提高定位精度。
3. **远场优先治定位**：`s > 40 m` 时定位项占 70% 以上，应改用差分 GNSS/视觉里程计，
   把 `b` 从 0.02 压到 0.017 以下即可满足 80 m 的精度要求。
4. **精度预算分配**：若要求 `s = 80 m` 仍满足 5°/95%，三项预算需满足
   `σ_geo ≤ 2.347°`，即 `σ_pos ≤ 1.64 m`；按"零偏 0.8°、控制 0.6°"不变，
   留给定位的预算只有 1.64 m（占标称 1.9 m 的 86%）。
5. **多站交会可放宽要求**：若同一目标有两站交会，单站 5° 的指向偏差会被交会几何部分抵消
   （见问题 2(1) 的 `σ_p` 公式），此时可把单站门限放宽到 8°~10°，换取更远的机动距离。
