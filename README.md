# 2026 第十二届数维杯（秋季赛）B 题 · 多车协同的无人机快速定位

100 m × 100 m 区域（原点西南角，x 轴正东、y 轴正北），5 栋长方体建筑 B1–B5、5 台车辆 V1–V5。
无人机告警以 (θ, R, H) 给出，目标坐标 = (50 + R cos θ, 50 + R sin θ, H)。
车辆可视为半径 1.5 m 的圆盘，须与建筑保持 ≥ 1.5 m 净空，速度 3 m/s，相机高 2 m，
云台俯仰 ∈ [−10°, 80°]、轴角速度 30°/s，单次观测 5 s。

## 方法学要点

- **共享模型单一口径**：五个子问题全部 `import common.model`，遮挡判定（闭长方体，含边界与相切）、
  可停留判定（原始轮廓净空 ≥ 1.5 m）、云台运动学（两轴同时，取较长者）无一处重复实现。
- **每题至少两条独立路径**，且至少一条不依赖优化搜索（闭式下界 / 蒙特卡洛 / 手算时间轴），用于判定另一条是否真收敛。
- **每题都做"是否等于理论下界"的自校验**：Q1 r 与 7.58206 m 差 0.04 mm；Q2(1) σ_p 与 σ√2·r_lb 完全相等；
  Q2(2) t_last 与手算分解差 1 ms；Q3 s_max 处 MC 通过率 0.94971 vs 解析 0.95。
