# 问题 2(1) 两站交会定位精度模型与 T2 的最优测站对

## 1 题意与约束

T2：(150°, 45 m, 35 m) → `T2' = (50+45cos150°, 50+45sin150°) = (11.0289, 72.5000)`，`H = 35 m`。

- 两车从**不同方位**同步观测同一目标，方位角测量误差独立同分布 `δα_i ~ N(0, σ²)`，`σ = 1°`。
- 测站必须落在 T2 的**可观测区域**（几何可停留 / 视线不遮挡 / 仰角 ∈ [−10°, 80°]）。
- **各车从初始位置到所分配测站的行驶时间 ≤ 30 s**（按绕建筑最短路计，`t = 路径长度/3`）。

## 2 精度模型

观测方程对目标水平位置 `p = (x_T, y_T)` 线性化：

```
∂α_i/∂p = ( (y_T−y_i)/r_i² , −(x_T−x_i)/r_i² ) = n_iᵀ / r_i ,   n_i = (−sin α_i, cos α_i)
⇒  n_iᵀ δp = r_i δα_i ,  i = 1,2
```

矩阵形式 `A δp = b`，`A = [n_1ᵀ; n_2ᵀ]`，`b = [r_1 δα_1, r_2 δα_2]ᵀ`：

```
Cov(δp) = σ² A⁻¹ diag(r_1², r_2²) A⁻ᵀ
```

由 `det A = ±sin γ`（γ 为两方位线交会角），并利用 `A⁻¹` 的两列均为单位向量
（`A⁻¹ = (1/sin γ)·M`，`M` 的两列范数为 1），可得**迹的闭式**：

```
tr Cov(δp) = σ² (r_1² + r_2²) / sin² γ
```

**精度指标（本问采用）**

```
σ_p = sqrt(tr Cov) = σ · sqrt(r_1² + r_2²) / |sin γ|        [m]
```

**为什么合理**：① `tr Cov = E[|δp|²]`，即位置误差的均方根，量纲为米，可直接与建筑尺度、
1.5 m 车体半径比较；② 迹是旋转不变量，不依赖坐标轴选择（对比"东向/北向分量"会随坐标旋转而变）；
③ 等于误差椭圆两半轴平方和的平方根，兼顾长短轴；④ 结构清晰：`1/|sin γ|` 反映交会几何，
`sqrt(r_1²+r_2²)` 反映距离放大，正是题目要求建模的两个因素。

同时用协方差矩阵特征值给出误差椭圆（长/短半轴、方向），作为方向的补充信息。

## 4 结果

### 4.1 最优测站对（最终答案）

| 项 | 值 |
|---|---|
| 车辆 | **V3 与 V5**（V3 初始 (14,86)、V5 初始 (50,93)） |
| 测站 1（V3） | **(5.3448, 73.7448)** |
| 测站 2（V5） | **(12.2737, 78.1841)** |
| 目标距离 | `r1 = 5.8188 m`，`r2 = 5.8188 m`（均等于仰角下界 `(35−2)/tan80°`） |
| 基线长度 | **B = 8.229 m** |
| 交会角 | **γ = 90.00°** |
| 方位角 | α1 = 347.65°，α2 = 257.65° |
| 行驶时间 | **t1 = 5.001 s**，**t2 = 13.510 s**（均 ≤ 30 s） |
| 精度指标 | **σ_p = 0.1436 m** |
| 误差椭圆 | 长半轴 = 短半轴 = **0.1016 m**（圆，各向同性），95% 误差圆半径 0.249 m |
| 仰角 | 两站均为 80.00°（云台上限） |

**闭式解释**：`σ_p` 关于 `r1, r2` 单调增、关于 `sin γ` 单调增，故最优解必然
`r1 = r2 = r_lb = 5.8188 m`（仰角上界）且 `γ = 90°`，此时

```
σ_p* = σ·√2·r_lb = 0.0174533 × 1.41421 × 5.8188 = 0.14362 m
```

且 `γ=90°`、`r1=r2` 时 `Cov` 各向同性，误差退化为半径 `r·σ = 0.1016 m` 的圆——这也是
"两站等距正交交会"的经典结论，可作为对模型的直观校验。

含 V2 的组合只能把其中一站放在 T2 东南侧较远处（`r=12 m`，`t=29.97 s` 已贴 30 s 上限），
精度损失 64%。**瓶颈不是 γ（都可接近 90°），而是"能不能把两站都放到仰角下界附近"**。

### 4.3 平局裁决

几何最优解只取决于 `(r, γ)`，与"由哪两辆车执行"无关；6 组车辆组合都能达到同一 `σ*`
（V1-V3、V1-V4、V1-V5、V3-V4、V3-V5、V4-V5）。按以下规则裁决：

> **R1** 取 `max(t1,t2)` 最小者——响应最快，且给云台转动/通信留余量；
> **R2** 并列时取车辆编号字典序最小者，保证唯一可复现。

结果 V3-V5（`max t = 13.56 s`）；若取 V1-V3，`max t = 20.2 s`，精度完全相同但部署慢 50%。

## 5 退化分析与处理策略

`σ_p = σ√(r1²+r2²)/|sin γ|`，在下列情形退化：

**(a) γ → 0° 或 180°（两方位线趋于平行）**：`sin γ → 0`，`σ_p → ∞`，两线近乎平行时
交点对角度误差极端敏感（`A` 趋于奇异，`cond(A) → ∞`）。取 `r1=r2=20 m` 的数值：

| γ | 1° | 5° | 10° | 20° | 30° | 45° | 60° | 90° | 150° | 175° |
|---|---|---|---|---|---|---|---|---|---|---|
| σ_p / m | 28.29 | 5.66 | 2.84 | 1.44 | 0.99 | 0.70 | 0.57 | **0.49** | 0.99 | 5.66 |

处理策略：
1. **硬约束** `γ ∈ [30°, 150°]`（工程惯例），把 `1/sin γ` 的放大倍数限制在 2 以内；
2. 若可行域内确实无法满足，则退化为"单站方位 + 另一站测距"或引入第三站做最小二乘，
   避免用近平行的两条线求交；
3. 在解算层面用 **Tikhonov 正则化**（加先验 `δp ~ N(0, Σ0)`）替代纯几何求交，使协方差有界。

**(b) 测站位于可观测区域边界**：可观测域的边界由三类不同约束构成（建筑禁入边界、
视线阴影边界、仰角临界圆、区域边界）。其中**视线阴影边界是不连续的**（越界即完全遮挡），
优化解可能贴在边界上，微小的定位误差就会使测站失效。处理策略：
1. 在可行域内加**净空裕度**（如距阴影边界 ≥ 2 m、仰角 ≤ 78°），把"数学最优"换成"可执行最优"；
2. 用**栅格枚举 + 局部精修**而非纯梯度法（本问即如此），避免梯度在不可导边界上失效；
3. 对最终解做**扰动敏感性检验**（±0.5 m 位移后是否仍可观测）。

**(c) 本问的最优点恰在仰角临界圆上（80°）**：`r = r_lb` 是硬下界，最优解必然贴边。
工程上若留仰角余量，代价如下（同取 γ=90°）：

| 仰角上限 | r_lb | σ_p | σ_p 相对增量 |
|---|---|---|---|
| 80°（题设） | 5.819 m | 0.1436 m | — |
| 78° | 7.014 m | 0.1731 m | +20.5% |
| 75° | 8.842 m | 0.2183 m | +52.0% |
| 70° | 12.011 m | 0.2965 m | +106.4% |

**建议**：报告值按题设 80° 给出；实装时若云台存在 1°~2° 指向零偏，宜取 78° 方案，
精度损失 20% 但可消除"仰角越界即失效"的风险。

## 6 验证

- **蒙特卡洛**（20 万次，非线性求交，不用一阶近似）：经验 RMS = 0.14364 m，
  一阶模型 0.14362 m，**相对偏差 0.012%**；经验 95% 分位 0.24865 m ≈ 2.4477×0.10156
  （圆误差分布的理论 95% 分位），说明线性化在该精度水平完全适用。
- 两套解法独立得到同一 `σ*`（0.14362 m）。
- 所有测站均通过三项约束复核，行驶时间按精确最短路复算（5.001 s / 13.510 s）。
